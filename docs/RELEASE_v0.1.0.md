# LearnLLM v0.1.0

首个完整学习版本，覆盖从零理解 LLM 所需的最小数学、Tokenizer、Attention、Decoder-only Transformer、TinyGPT 预训练与生成、真实 assistant-only SFT、LoRA、可归因 Tiny RAG 和本地工具 Agent。

## 获取方式

- 阅读仓库 `README.md`，在项目 `.venv` 中运行全部实验。
- 下载本 Release 附带的中文学习指导 PDF。
- 按八周 Milestone 创建学习日志 Issue，记录预测、结果、失败案例与复述。

## 验证范围

- Windows + CPU。
- Python 3.11 与 3.12。
- 自动测试和环境隔离检查。
- PDF 可重建性、页数、目录文本与关键章节检查。
