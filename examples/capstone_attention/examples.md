# 成功与失败样例

## 成功信号

- 小 `d_k` 时，缩放与不缩放的差异有限。
- 大 `d_k` 时，未缩放组最大权重明显升高、熵明显降低。
- 开启 causal mask 后，严格上三角的权重全部为 0。

## 失败案例与诊断

1. **每次结果都不同**：没有固定随机种子，无法把变化归因于缩放。
2. **scaled 与 unscaled 完全相同**：可能误把两组都调用了带缩放的公共实现。
3. **第一行权重出现 NaN**：causal mask 方向可能反了，导致整行都被屏蔽。
4. **只比较一次随机矩阵**：样本方差太大，单次现象不足以支持趋势结论。
5. **把熵更低解释为模型更聪明**：分布更尖只描述置信集中程度，不等于预测更正确。
